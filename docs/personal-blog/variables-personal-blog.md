# Variables for Personal Blog

- payload-blog-source-dir: < workspace-full-path >/payload-blog
- payload-blog-docs-dir: < workspace-full-path >/payload-blog-docs

- vm-payload-user: Virtual Machine system user name
- vm-payload-user-key: SSH key for vm-payload-user

- dev-domain-name: devblogserver.my-domain.com
- servername: 
    vm: devblogserver
    vps: server1

- github-app-name-vps: app-personal-blog-vps

For other variables, [look for](../cpm-cms/variables.md) /docs/cpm-cms/variables.md)
